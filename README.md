# Nemotron Metaculus Forecasting Bot

A Metaculus forecasting bot based on the official
[Metaculus/metac-bot-template](https://github.com/Metaculus/metac-bot-template).

The bot uses **NVIDIA Nemotron 3 Ultra 550B** through OpenRouter's free
model endpoint for the entire LLM pipeline.

## Model

The bot is locked to:

```text
nvidia/nemotron-3-ultra-550b-a55b:free
