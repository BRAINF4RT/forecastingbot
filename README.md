# VibeThinker Metaculus Bot

A Metaculus forecasting bot built on the official
[Metaculus/metac-bot-template](https://github.com/Metaculus/metac-bot-template)
scaffolding (`ForecastBot`, `MetaculusClient`, prediction aggregation, etc.
from the `forecasting-tools` package), with a custom forecasting brain and
research pipeline.

## Models and tools

| Task | Model / tool |
|---|---|
| **Forecast reasoning (main brain)** | `WeiboAI/VibeThinker-3B` via Hugging Face Inference Providers → Featherless AI |
| **Search-query generation** | `nvidia/nemotron-3-ultra-550b-a55b:free` on OpenRouter |
| **Research summarization** | `nvidia/nemotron-3-ultra-550b-a55b:free` on OpenRouter |
| **Parsing brain output → structured prediction** | `nvidia/nemotron-3-ultra-550b-a55b:free` on OpenRouter via `structure_output` |
| **Web search** | DDGS |
| **Page scraping** | trafilatura → BeautifulSoup fallback → DDGS snippet fallback |

The OpenRouter model is intentionally used for the research/helper stages and
structured-output parsing. The main forecasting reasoning is generated by
VibeThinker-3B through Hugging Face.

```text

       │
       ▼
bot.run_research()
       │
       ▼
research/pipeline.py

       ├── research/scraper.py

       │     ├── trafilatura.extract()
       │     ├── BeautifulSoup fallback

       │

       │
       ├── Build forecasting prompt
       │
       ├── Hugging Face / Featherless
       │     └── WeiboAI/VibeThinker-3B
       │           └── Generate forecast reasoning
       │
       └── OpenRouter
             └── nvidia/nemotron-3-ultra-550b-a55b:free

       │
       ▼
ForecastBot
       │
       ▼
Metaculus
